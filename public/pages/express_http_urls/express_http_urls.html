Express og HTTP

Express gør det nemmere at lave en web server med Node.js. Browseren sender en HTTP request, og serveren svarer med en response.

Routes

En route bestemmer, hvad serveren gør ved en bestemt URL. Den kan for eksempel sende en side, når nogen åbner forsiden.

Requests og responses

En request er det, browseren sender til serveren. Serverens response indeholder svaret og en status code, som fortæller, hvordan det gik.
