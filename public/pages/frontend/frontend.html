Fetch og security

Fetch lader JavaScript hente data fra en server, mens siden er åben. Det betyder, at hele siden ikke behøver at blive genindlæst.

Requests og responses

Fetch sender en request og får en response tilbage. Tjek først, at requesten lykkedes, og brug derefter dataene.

Vis data sikkert

Vis tekst som tekst, især hvis den kommer fra en bruger. Så bliver den ikke fortolket som HTML.
