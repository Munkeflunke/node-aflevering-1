Node.js noter

Her er korte noter om JavaScript, Node.js og Express. Tænk på dem som en hurtig forklaring, du kan vende tilbage til.

Emner

  • JavaScript: variables, data types og functions.
  • Node.js og npm: kør JavaScript og brug packages.
  • Express og HTTP: routes, requests og responses.
  • REST API: arbejd med data gennem HTTP methods.
  • Fetch og security: hent data og vis det sikkert.
  • Modules og static files: del programmet op og server filer.
  • Server-side rendering: lav sidens HTML på serveren.
