JavaScript

JavaScript bruges i browseren til at få hjemmesider til at reagere. Med Node.js kan du også køre JavaScript på din computer eller en server.

Variables og data types

En variable giver en værdi et navn. Værdien kan for eksempel være en string med tekst, et number eller et array med flere værdier.

Functions og control flow

En function samler noget, programmet skal gøre. Conditions vælger mellem handlinger, og loops gentager en handling.
