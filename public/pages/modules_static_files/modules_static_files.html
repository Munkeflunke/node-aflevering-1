Modules og static files

Et module er en separat fil med en del af programmet. Det gør det lettere at finde rundt, når programmet består af flere filer.

Export og import

Et module kan exportere en function eller en værdi. Et andet module kan importere den og bruge den.

Static files

CSS, billeder og andre filer, som browseren skal hente, kaldes static files. Serveren kan gøre dem tilgængelige fra en offentlig mappe.
