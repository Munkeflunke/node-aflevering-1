Node.js og npm

Node.js gør det muligt at køre JavaScript uden for browseren. Det kan for eksempel bruges til en web server.

npm og packages

npm følger med Node.js og hjælper med at installere packages. Et package er kode, du kan bruge i dit eget project.

Dependencies og scripts

Dependencies er de packages, projektet bruger. I package.json kan du også skrive scripts, så du nemt kan starte projektet.
